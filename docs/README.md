## Versioning practice

When a substantive revision is made, keep the working document clearly identifiable and use Git commit messages that describe the change. Avoid overwriting an important milestone without recording what changed.

Suggested milestone labels:

- Draft — working revision
- Review — submitted for supervisor/academic review
- Revised — changes incorporated after feedback
- Final — approved submission version
